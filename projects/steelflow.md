# SteelFlow

**Focus:** Full-stack ERP and logistics  
**Stack:** Next.js, React, TypeScript, Supabase, Tailwind CSS  
**Context:** Mapúa capstone; private source

## Project

SteelFlow is an ERP and logistics application for steel-fabrication operations. The repository includes administration, company management, inventory, inventory reporting, and delivery-tracking work.

## Engineering scope

- A Next.js application with React and TypeScript.
- Supabase integration for application data and authentication.
- Inventory reports and charting components.
- Mapping dependencies for logistics interfaces.
- Separate application pages for operational and administrative workflows.

## Why it belongs in a cybersecurity portfolio

Building a business application provides practical context for application security: authentication, authorization, validation, and the consequences of exposing operational data. It complements my security work with experience implementing the systems being assessed.

This summary does not claim that the application has passed an independent security audit.
